Cómo funciona cada lección

La librería algolib trae la API y los tests de los 13 labs desde el primer día. Al principio todo aparece como [TODO]; el trabajo del alumno es dejarlo en [ OK ].

make lab01        # C, C++ y Rust
make c-lab01      # solo C
make cpp-lab01    # solo C++ (AddressSanitizer + UBSan)
make rust-lab01   # solo Rust
